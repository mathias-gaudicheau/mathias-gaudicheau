## Ma façon de travailler avec l'IA

- **L'outil prépare, l'humain décide.** Aucun de mes outils ne publie, ne postule ni n'envoie quoi que ce soit tout seul.
- **Les règles avant le code.** Chaque projet part d'un brief écrit et d'une courte liste de garde-fous non négociables que l'agent doit suivre. Ils vivent dans le dépôt, à côté du code (`CLAUDE.md`, `AGENTS.md`) : on voit exactement comment le travail a été piloté.
- **Les tests comme contrats.** Dans Le Cercle, chaque règle de jeu est numérotée, et la compilation échoue si une règle n'a pas son test.
- **Mesurer, puis affirmer.** Je n'annonce un chiffre que quand la chose a vraiment tourné.
